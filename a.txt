  To get started:

  1. Install Bun (if not installed): curl -fsSL https://bun.sh/install | bash
  2. Install dependencies:
  cd my-slow-news
  bun install
  3. Set up environment:
  cp .env.example .env
  # Edit .env with your API keys
  4. Register Reddit app at https://www.reddit.com/prefs/apps (select "script" type)
  5. Start services:
  docker compose up -d surrealdb
  bun run db:init
  6. Generate your first digest:
  bun run digest

  The PRD is saved at ~/.claude/plans/precious-yawning-axolotl.md for reference.
